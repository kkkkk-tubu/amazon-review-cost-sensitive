# 重采样类方法对照(自实现 ROS / RUS / SMOTE)

前面几组实验改的是**损失函数**,这一组改的是**数据分布**,两类方法互为补充。

三条必须守住的规矩:

1. 采样只在训练集上做,验证集与测试集保持原样 —— 在测试集上采样等于信息泄漏;
2. SMOTE 在稀疏 TF-IDF 上可直接插值,合成样本的非零位置是两者非零位置的并集,
   不会变稠密,因此无需降维;
3. 仅邻居搜索放在 SVD-100 的低维空间,避免 4 万 × 4 万的稀疏余弦相似度矩阵过大。

TF-IDF 100000 维, 拟合 30.0s
训练集 254902 行, 正 214927 / 负 39975

**无采样 (对照)**: 训练集 254902 行, 正 214927 / 负 39975, 采样耗时 0.0s
**随机过采样 ROS**: 训练集 429854 行, 正 214927 / 负 214927, 采样耗时 0.1s
**随机欠采样 RUS**: 训练集 79950 行, 正 39975 / 负 39975, 采样耗时 0.0s
**SMOTE (k=5)**: 训练集 429854 行, 正 214927 / 负 214927, 采样耗时 10.0s

## 3. 结论

- 不做任何采样时,验证集选阈值后 macroF1 = 0.8917。
- 四种配置里最好的是 **随机过采样 ROS**,macroF1 = 0.8945,
  相对无采样的变化为 +0.0029。

- **ROS(随机过采样)**:负类召回 0.8141 → 0.8040,精度 0.8202 → 0.8396,macroF1 变化 +0.0029。
  它是本组里**唯一略微超过基线**的方法,但幅度不到 0.3 个百分点。
  值得注意的是它的方向与加权损失**相反**:召回略降、精度略升。
  复制少数类样本相当于把决策边界往少数类一侧推得更稳,而不是单纯地放松判负的门槛,
  因此这次 F1 是净提升的,只是幅度有限。
- **RUS(随机欠采样)**:负类召回 0.8141 → 0.7837,精度 0.8202 → 0.8125。
  训练集从 254902 缩到 79950 行,丢掉了 174952 条多数类样本 —— 信息损失是它的主要代价。
- **SMOTE**:负类召回 0.8141 → 0.8252,精度 0.8202 → 0.8105,macroF1 变化 +0.0001 —— 几乎与不采样持平,
  而且**不如 ROS**。一个可能的原因是稀疏 TF-IDF 上的插值语义薄弱:
  合成样本是两篇评论词向量的加权平均,词袋上成立,语义上往往是拼凑出来的混合文本,
  反而给训练引入了噪声。

### 值得记录的一点

三种方法里表现最好的是**最简单的 ROS**(0.8945),
反而超过了更复杂的 SMOTE(0.8918)。
这说明在本任务上,合成样本带来的收益不足以抵消它引入的分布噪声;
而直接复制少数类样本虽然朴素,却没有破坏任何真实样本的分布。

**总体判断:三种重采样里只有最简单的 ROS 略微超过了「什么都不做 + 调阈值」,**
且幅度很小,仍不及前面自实现 CE 基线的 0.8962。这与修改损失函数那组实验的结论
是一致的 —— 本任务的难点不在类别频率,而在星级标签噪声与文本内部的混合情感,
改变类别分布或损失权重都触及不到它。
